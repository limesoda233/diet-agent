## 范围与边界

- 1—3 个连续日期、相同的所选餐次集合，最多九个任务，每任务一餐；不支持逐日不同餐次或编辑旧计划，要求澄清。
- 本轮/会话/明确记忆与推断偏好有不同来源；推断只影响排序。过敏或当前不能核验的价格/营养数值/工具/时长要求不输出已满足计划。
- 餐食只从 MySQL 获取；PUBLIC/PERSONAL 不混合，不依赖 embedding/RAG/视频。
- 上下文和候选结束前复核是检查点，不保证与所有并发用户编辑串行化。数据库取消采用查询/事务超时和提交前取消/截止检查，驱动不保证即时终止。
- 实际功能入口、迁移和开关见 [运行指南](../../guides/meal-planning.md)。未自动修改用户数据库或密钥配置。
