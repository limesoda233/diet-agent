改进来自补充食材知识、硬条件前置及结构化软排序，不能归因于向量检索。固定轨道只证明正确约束输入下的检索效果。单次未预热延迟不用于性能优劣结论。

解析轨道另有 **10 条解析异常、16 个标注条件未提取、0 个额外条件**。成功解析的 54 条中，按原始评测标注计算仍有 1 个禁用食材违规结果、24 个缺少必需食材结果，分别影响 1 和 8 条查询。不能对完整对话宣称硬约束违规为零。

漏项混合了规则覆盖不足和标签口径差异。例如“不要牛奶或酸奶”在初稿中还排除了黄油，“有番茄加豆腐的做法吗”被标注为两个必需食材；有限解析器没有做这些推断。先复核这些语义与标注，再在后续规格中扩展规则；本次不通过改测试标签抬分。

报告：`target/evaluation/retrieval/report.json`、`target/evaluation/hybrid-retrieval/structured-fixed/report.json`、`structured-parsed/report.json`。报告记录语料、查询、实现哈希和解析明细；目录被 Git 忽略，本文件保存关键可复核结论。
